# FadeBeacon

FadeBeacon is a distributed, real-time data processing platform that leverages event-driven architecture for scalable anomaly detection and response.

With FadeBeacon, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/FadeBeacon.git`
2. `cd FadeBeacon`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
